# Token metadata directory

Token entries use this path convention:

```text
chains/<chainId>/<lowercase-token-address>/metadata.json
chains/<chainId>/<lowercase-token-address>/logo.png
```

`metadata.json` is the contributor-authored source. `logoUrl` is intentionally omitted and generated by `npm run tokens:build`.

The formal JSON Schema is available at [`schema/token-metadata.schema.json`](schema/token-metadata.schema.json).
